# Customer Success & Technical Account Management Knowledge Base

Structured Markdown knowledge base distilled from the connected Notion handbooks.

## Knowledge areas
- [TAM](TAM/README.md): integrations, identity, networking, architecture, data, enablement and engineering escalation.
- [CSM](CSM/README.md): lifecycle, onboarding, adoption, health, stakeholder management, QBRs, retention, expansion and metrics.
- [Templates](templates/README.md): technical discovery, escalation, success plans and QBRs.

## Operating principles
Start with customer outcomes; diagnose before prescribing; record evidence, ownership and next actions; protect customer data; distinguish verified facts from assumptions; measure outcomes rather than activity.
